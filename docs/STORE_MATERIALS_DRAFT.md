## 应用描述(长;官方口径 + 当前版本实际能力,**不虚标**)
uniTerm 是开源全能终端软件(Apache-2.0)的 KaihongOS 适配版,与官方版本同源同格式,配置文件互导互通。

当前版本(1.0.0)已支持:
- **SSH 远程终端**:完整交互终端(ANSI 颜色/键盘映射/窗口自适应/会话保活),密码、密钥、身份库三种认证
- **SFTP 文件传输**:远程目录浏览、上传下载
- **连接管理**:分组/收藏/最近连接;兼容官方 connections.json 与 .utm 配置(含加密 .utm)双向互导
- **安全**:主密码 + PBKDF2/AES-256-GCM 本地加密,密文落盘
- **细节**:GBK 编码主机、退格键三模式(del/bs/vt220)、多编码支持

官方完整版另支持 RDP/VNC/Telnet/数据库/Kubernetes/AI 助手等 30+ 协议能力,将按官方路线图在后续版本逐步适配提供。
