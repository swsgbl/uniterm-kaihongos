# 任务书 035:M6 棒1 — GUI 体验全面升级(用户实测缺陷清单)

## 背景
用户实测后提出明确缺陷(原话要点)+要求全面体验升级。**这棒的验收标准=用户痛点逐项消除**,不是"能跑就行"。

## A. P0:用户点名缺陷(逐项修+实证)
1. **模型配置保存失败**:AI 设置填完各字段保存不了——排查 LlmConfigStore 的写盘路径/格式/权限(此前 e2e 是 root 直写 llm_config.json 绕过了应用内保存路径,应用内真实保存链路很可能从未通过);修到:应用内填写→保存→重启后配置仍在(冷启 dump 验证)。
2. **密钥输入栏看不见**:API Key 输入框渲染异常(可能 secure 类型样式/高度/占位问题)——修复到清晰可见(密文显示但框体/标签/占位完整)。
3. **无任何提示**:保存成功/失败、连接成功/失败等关键操作**必须有无障碍反馈**(toast/横幅/状态色),逐处补。
4. **明暗主题不能控制全部界面**:全工程扫硬编码颜色(十六进制/Color.Xxx)——所有组件改走 UniTheme token;深浅切换后**逐页截图对比**两套主题全覆盖(StartTab/终端/SFTP/设置/AI/监控/各 DB/远程桌面 Tab/ConnForm/身份面板/导入导出弹窗)。
5. **图标不明显**:侧栏 7 视图/顶栏/类型徽标/按钮图标视觉权重提升(尺寸/描边/选中态/悬停态对比度)。
6. **无悬停提示**:所有图标按钮加 tooltip(名称+一句话功能;ArkUI onHover+Popup 或 bindTooltip 等价物)——桌面鼠标形态必备。

## B. 系统性 UX 清单(全面扫)
- 空状态(无连接/无会话/无历史)有引导;加载态有指示;错误态有文案+重试
- 焦点可见性(键盘可达性)、双击/右键菜单一致性
- 危险操作确认(删除连接/断开)
- 字号/行距/密度统一(对照官方截图)
- 中文文案统一(无中英混杂/无占位英文)
